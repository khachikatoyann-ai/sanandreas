# Los Santos Advanced (sanandreas)

Production-grade 3D open-world action-driving sandbox game built with **Godot 4**, **Vulkan Mobile** renderer, **Jolt 3D Physics**, and modular GDScript architecture.

## Features
- **Open-World Los Santos District**: High-density skyscrapers, multi-lane avenues, palm tree boulevards, beachfront coastline, ramps, and sports cars.
- **Physics Vehicle Controller**: 4-wheel Ackermann steering, multi-gear transmission curves, handbrake drift mechanics, and tire smoke FX.
- **LSPD Pursuit AI**: Dynamic wanted level system (1–5 Stars), tactical pursuit AI, roadblock interception, and PIT maneuvers.
- **Hitscan Combat & Hijacking**: Third-person camera with touch-drag aiming, muzzle flash bloom FX, pedestrian reactions, and seamless carjacking.
- **Mobile HUD**: Virtual touch joystick, dynamic context buttons (driving vs on-foot), circular radar minimap, wanted stars, and speedometer.
- **Automated iOS IPA Builder**: GitHub Actions workflow running on macOS with Xcode to compile unsigned IPAs for Sideloadly installation.
